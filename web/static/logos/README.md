# Organisation logos

These square marks credit model makers, hosts and storage providers (`src/lib/chat/routing/catalog.ts`,
`OrgLogo.svelte`). They are stored as local files so that Alpha's privacy panels don't make the
browser contact third-party domains to draw a logo.

## Sources

Each file is resized to a 96×96 PNG.

- Hugging Face organisation avatars (`huggingface.co/api/organizations/<org>/avatar`): swiss-ai,
  BSC-LT (bsc), aisingapore (ai-singapore), speakleash, zai-org (zhipu), mistralai (mistral),
  CohereLabs (cohere), huggingface, openrouter.
- Cloudflare: the Hugging Face organisation avatar (`huggingface.co/api/organizations/Cloudflare/avatar`),
  converted from WebP.
- Site touch icons: infomaniak.com (apple-touch-icon), cscs.ch (touch-icon-ipad-retina).
- Mozilla Data Collective: the "M" glyph cropped from the collective's own wordmark
  (`mozilladatacollective.com/_next/static/media/mdc-logo.*.svg`) onto a white square, because the
  collective publishes no square mark.
- Common Voice: `commonvoice.mozilla.org/img/voice-touch-icon.png`.
- Featherless: the Hugging Face organisation avatar
  (`huggingface.co/api/organizations/featherless-ai/avatar`), converted from WebP.
- Phoeniqs: the site icon `phoeniqs.com/img/Phoeniqs_You_Tube_714415b815.png`
  at 96×96, converted from WebP.
- NextBit: no file. It renders as a monogram.

## Use and removal

The marks belong to their organisations and appear only beside the name of the organisation they
identify, as attribution. They imply no endorsement of or by it. `huggingface.png` is the
Hugging Face company mark. This tree doesn't ship the HuggingChat product mark.

A rights holder who objects to a mark can open an issue to have it removed. The catalog then shows a
monogram.
