summary: Versioning — the design system has a version, a changelog, and a gate that will not let either be forgotten
---

The version is derived from this folder: one entry per change, `major.minor.patch` counts entries
of each kind. `pnpm ds:change "<summary>"` records a change and works out the bump from the
public surface; `pnpm lint:design` fails on anything unrecorded. The lint plugin reports this
version as its `meta.version`, so ESLint's cache is invalidated when a rule changes.

This entry's surface block is the snapshot every later entry is measured against (640 public
names). Entries before it were written from git history and carry notes only.
